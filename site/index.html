Mokted

Play Roblox on Linux like it was made for your PC. Mokted is Mocktail, tuned to feel fast and look sharp.

Download AppImage Install with Flatpak

AppImage

chmod +x Mokted-x86_64.AppImage ./Mokted-x86_64.AppImage

Flatpak

flatpak install --user https://sdqfrmnsyh.github.io/mokted/mokted.flatpakref flatpak run io.github.sdqfrmnsyh.mokted

DEB, RPM and pacman

sudo apt install ./mokted_<version>-1_amd64.deb sudo dnf install ./mokted-<version>-1.x86_64.rpm sudo pacman -U mokted-<version>-1-x86_64.pkg.tar.zst

Build from source

git clone --recurse-submodules https://github.com/sdqfrmnsyh/mokted.git cd mokted && make build ./build/mocktail

What's different

  • Lower input lag. Frames are shown as soon as they are ready.
  • Sharper textures, with your own PNG overrides if you want them.
  • ETC2 textures render correctly on desktop GPUs.
  • No more error 319 kicks after joining a server.
  • Roblox sees your real RAM and screen size.
