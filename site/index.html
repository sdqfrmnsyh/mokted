Mokted

Play Roblox on Linux like it was made for your PC. Mokted is Mocktail, tuned to feel fast and look sharp.

Download AppImage Install with Flatpak

AppImage

chmod +x Mokted-x86_64.AppImage ./Mokted-x86_64.AppImage

Flatpak

flatpak install --user Mokted-x86_64.flatpak flatpak run io.github.sdqfrmnsyh.mokted

DEB, RPM and pacman

sudo apt install ./mokted_<version>-1_amd64.deb sudo dnf install ./mokted-<version>-1.x86_64.rpm sudo pacman -U mokted-<version>-1-x86_64.pkg.tar.zst

Build from source

git clone --recurse-submodules https://github.com/sdqfrmnsyh/mokted.git cd mokted && make build ./build/mocktail

What's different

  • Built for low-end x86_64 hardware, with tuning specifically aimed at Excavator-class CPUs.
  • Removes the busy-wait engine fallback so the render thread keeps its core instead of burning CPU.
  • Runs the input pump at 120 Hz instead of 240 Hz, cutting polling overhead without hurting feel.
  • Caps the scheduler pool to cores minus one to avoid oversubscription and context-switch churn.
  • Disables text overlay compositing by default to avoid extra Vulkan submit and dispatch costs.
  • Turns off Discord Rich Presence and gamepad polling unless you explicitly enable them.
  • Adds exclusive fullscreen support while keeping borderless fullscreen as the safer default.
